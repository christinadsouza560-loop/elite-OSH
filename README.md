# Snake and Ladder

A simple command-line Snake and Ladder game built with Python.

## Features

- 2 to 4 players
- Dice rolling
- Snakes that move players down
- Ladders that move players up
- Exact roll required to reach square 100

## How to Run

```bash
python file.py
```

Follow the prompts in the terminal to enter player names and roll the dice.
